# 厦门理工台球社管理系统

面向社团负责人和社员的内部管理系统。系统不包含收费、会员期限、场地租赁、器材管理或现场赛事大屏。

## 已实现功能

- 成员新增、修改、软删除、搜索、CSV 批量导入和一键导出
- 负责人、社员两种角色字段及服务端负责人操作校验
- 正式比赛创建、单败/双败、几局几胜、让球、参赛成员和种子设置
- 一键生成单败晋级签表；双败自动生成败者组流转和总决赛
- 正式比赛比分录入、自动晋级、积分及 Elo 自动更新
- 社员约战：发起、接受、提交比分、对方确认、负责人审核及自动计分
- 积分榜、Elo、胜负记录和数据分析
- 操作日志、完整 JSON 数据备份与覆盖恢复
- D1/SQLite 持久化数据，不使用浏览器本地存储保存业务数据
- 桌面和移动端响应式后台界面

## 首次运行

```powershell
git clone https://github.com/Nii275/billiards-club-management-system.git
cd billiards-club-management-system
npm ci
npm run setup:local
npm run dev
```

需要 Node.js 22.13 或更高版本。随后访问终端显示的本地地址。首次运行数据库为空，请在“成员管理”中录入成员。

## 数据与隐私

公开仓库不包含本地 D1/SQLite 数据库、成员名单、数据库备份或运行缓存。`.wrangler/` 与 `*.sqlite` 已加入忽略规则，请勿将包含个人信息的数据库提交到公开仓库。

## CSV 导入格式

第一行为表头，列顺序如下：

```text
姓名,性别,专业年级,学号,联系方式,角色,标签,状态
```

角色填写“负责人”或“社员”，状态填写“在社”“暂停活动”“退社”或“毕业”。

## 测试

```powershell
npm test
npx tsc --noEmit
npm run lint
npm run build
```

启动开发服务器后，可另开终端执行完整 API 流程测试：

```powershell
npm run test:api
```

该测试会覆盖成员增改删、单败签表、双败总决赛、正式比赛计分、约战三级确认、积分/Elo、日志、备份及恢复。
